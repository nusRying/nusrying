## 🔬 Current Research

### Interpretable Skin-Lesion Classification

My MPhil research investigates a hybrid framework combining:

* Lightweight Vision Transformers
* Evolutionary Learning Classifier Systems
* Interpretable Boolean code fragments
* Explainable IF–THEN decision rules
* Handcrafted image descriptors
* Feature and classifier transfer
* CPU and mobile-friendly inference

The goal is to create an interpretable, efficient, and robust system for melanoma and skin-lesion classification using datasets such as **HAM10000 and ISIC**.

### 📑 AI Bookkeeping Agent and Multi-Tenant Platform

**Technologies:** n8n, LangChain, Claude, Supabase, Nextcloud, Next.js

* Production Telegram and web-based AI bookkeeping assistant
* Extracts structured information from invoices and receipts
* Organizes documents inside a structured Nextcloud file system
* Tracks financial records using Supabase
* Uses an **83-node LangChain agent** with a dynamic skill system

An AI-powered document-forensics system for detecting:

* Digitally manipulated identity documents
* Printed document replicas
* Structural inconsistencies
* Suspicious text and image regions
* Potentially fraudulent identity documents

The platform combines multiple forensic filters with trained and heuristic scoring, automatic threshold calibration, custom-model training, and a trust-score dashboard.
